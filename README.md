# ⌨️ Typing Practice Studio (टंकण अभ्यास केंद्र)

A lightweight, feature-rich web application built to help users practice Hindi and English typing. Designed specifically for standard Devanagari and Kruti Dev layout practice alongside general knowledge preparation and speed tracking.

---

## ✨ Features

* **Hindi GK Question Sets:** Includes built-in, refreshable General Knowledge question sets in Hindi to practice real-world typing scenarios[cite: 1].
* **Countdown Timer:** Integrated timer with quick-set options (2, 5, 10, or 15 minutes) and a visual red-alert status with sound feedback when time expires[cite: 1].
* **Multi-Font Support:** Switch seamlessly between:
  * Standard Hindi (*Noto Sans Devanagari*)[cite: 1]
  * Kruti Dev 010 (*Kruti Dev 010* font family)[cite: 1]
  * English (*Poppins*)[cite: 1]
* **Dynamic Font Sizing:** Increase or decrease text size on the fly for comfortable reading and typing[cite: 1].
* **Live Writing Pad Stats:** Real-time word and character counters integrated into a ruled notebook UI[cite: 1].

---

## 🛠️ Built With

* **HTML5** – Page structure and semantic elements[cite: 1]
* **CSS3** – Custom styling, CSS Grid, notebook line aesthetics, and flexbox layout[cite: 1]
* **JavaScript (ES6)** – DOM manipulation, timer intervals, Web Audio API, and language/font logic[cite: 1]
